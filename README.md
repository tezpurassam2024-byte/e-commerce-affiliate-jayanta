# TechReview Hub & Affiliate Platform

A modern, high-performance tech review, gadget comparison, and affiliate aggregation platform built with React 18, TypeScript, Tailwind CSS, Express, and Vite.

## Features

- **Ranked Tech Buying Guides**: In-depth curated reviews and head-to-head comparisons across 20 serialized laptops, smartphones, tablets, audio gear, and peripherals.
- **Affiliate & Price Tracking**: Real-time Amazon affiliate link integration with live ASIN matching, verified price points, and localized currency formatting.
- **Interactive Comparison Engine**: Multi-product specification matrix with side-by-side spec comparison, pros/cons, and tailored user recommendations.
- **Search & Smart Filters**: Instant client-side search across brands, categories, price brackets, and hardware specifications.
- **Responsive Modern UI**: Built with Tailwind CSS and Lucide React icons, optimized for mobile, tablet, and desktop viewports.

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React icons
- **Backend & Middleware**: Express, Vite middleware mode
- **Build Tooling**: Vite, esbuild, TypeScript compiler

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd <repo-folder>

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build frontend and compile backend
npm run build

# Start production server
npm start
```
